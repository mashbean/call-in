# Call-in brand

## Name and promise

- Product: **Call-in**
- Chinese: **簡報叩應**
- English line: **Call-in for your slides**
- Chinese line: **讓你的分享，可以即時叩應**
- Canonical URL: `https://call-in.mashbean.net`

Use `Call-in` in prose and `CALL-IN` for the compact wordmark. Do not use Live Deck or Live Desk for new public copy; those names remain only in documented compatibility identifiers.

## Mark

The mark uses an abstract bell curve that folds into a response loop. The large peak represents the room's aggregate signal; the coral node represents one person's call-in joining the shared shape.

- `public/brand/call-in-mark-light.png`: deeper gradient for light surfaces.
- `public/brand/call-in-mark-dark.png`: brighter gradient for dark surfaces.
- `public/brand/call-in-favicon.png`: compact dark-surface mark.

Keep clear space around the mark and do not add a speech bubble, presentation frame, microphone, chart axes, or literal bell.

## Image-generation direction

The source direction was: a premium, highly abstract bell-curve mark made from one continuous flowing curve, subtly folding into a call-and-response loop; electric violet through indigo to cyan, with one small coral response node; geometric, minimal, crisp at 24px, transparent background, no text, mockup, shadow, 3D treatment, literal bell, speech bubble, presentation screen, microphone, chart, or axes.
