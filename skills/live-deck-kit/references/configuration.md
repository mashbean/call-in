# Configuration

The private setup link returned by the hosted `/new/` flow is the primary configuration surface. It consumes its access credential from a URL fragment, stores it in tab-scoped `sessionStorage`, and saves the public event contract in that event's Durable Object through `/api/events/:eventId/admin/config`. `public/event.config.json` remains the version-controlled default for source-configured self-hosting. Neither public configuration location contains secrets.

## Fields

- `eventId` is a lowercase slug. Changing it selects a different Durable Object and therefore a different data set.
- `eyebrow`, `title`, `description`, and `dashboardTitle` control public copy.
- `deckUrl` is the return link from the audience page.
- `theme` maps the event palette to CSS variables.
- `difficulty.labels` must contain exactly five labels ordered from easiest to hardest.
- `question.maxPerDevice` accepts 1 to 100. The default is 20.
- `question.lenses` uses the four supported ids `clarify`, `chorus`, `bridge`, and `keeper`. Labels and descriptions are editable.
- `reactions` uses the four supported ids `applause`, `insight`, `resonate`, and `pause`. Emoji and labels are editable.
- `polls` accepts at most eight polls. Each poll needs a unique slug and two to six options.
- `moderation.enabled` turns on the code-of-conduct and fixed-alias question flow.
- `moderation.presentationDelaySeconds` accepts 0 to 30 seconds. The default example uses 8.
- `moderation.questionCooldownSeconds` sets the normal per-device question cooldown.
- `moderation.questionsPerTenMinutes` limits bursts while keeping the total event limit.
- `moderation.slowModeSeconds` sets the longer cooldown used by slow mode.
- `moderation.flags.enabled` adds reason-based audience reports. Reports never expose public counts.
- `moderation.flags.maxPerDevice` limits how many distinct questions one event identity can report.
- `moderation.flags.autoHoldMin` and `autoHoldMax` bound the number of independent reports needed before a question is temporarily held.
- `moderation.flags.autoHoldParticipantRatio` raises that threshold as the registered audience grows. The example uses 3%, bounded to three through five reporters.
- `moderation.codeOfConduct` contains a version, title, summary, and two to eight public rules. Change the version when participants must accept revised rules.

## Wrangler variables

- `ROOM_ID` selects the room within an event configuration. Keep `default` for one deployment per event.
- `ALLOWED_ORIGINS` is a comma-separated exact allowlist for custom API clients. The embedded dashboard iframe does not need it.
- `ADMIN_TOKEN_SHA256` is generated by `npm run admin-token`. The plaintext token is stored only in `.live-deck-admin-token`.
- `MODERATOR_TOKEN_SHA256` is generated by `npm run moderator-token`. The plaintext token is stored only in `.live-deck-moderator-token`.
- `ADMIN_TOKEN` and `MODERATOR_TOKEN` are optional encrypted Worker secrets for the permanent single-event self-hosted root routes.

The service prefers a valid committed SHA-256 hash when one exists; otherwise it accepts the corresponding Worker secret. Do not configure both paths with unrelated values and assume either one will work.

## Admin operations

Open the hosted event's private setup link to edit it without changing source files. The wizard keeps the generated credential in `sessionStorage`, posts the complete validated configuration, and cannot change `eventId`. Existing responses remain in place after a configuration update. Hosted beta events expire after seven days.

Export current state

```bash
curl -H "Authorization: Bearer $LIVE_DECK_ADMIN_TOKEN" https://SERVICE/api/admin/export
```

Reset current state

```bash
curl -X POST -H "Authorization: Bearer $LIVE_DECK_ADMIN_TOKEN" https://SERVICE/api/admin/reset
```

Resolve the exact service URL before running either command. Never print the token in logs or chat output.

## Moderator console

Open `/moderate/` on the deployed service and enter the moderator token. This role can review report reasons, confirm or reverse a temporary community hold, hide or restore questions, change a participant's question state, and change the session mode. It cannot export or reset data.
