# Configuration

`public/event.config.json` is the public event contract. It contains no secrets.

## Fields

- `eventId` is a lowercase slug. Changing it selects a different Durable Object and therefore a different data set.
- `eyebrow`, `title`, `description`, and `dashboardTitle` control public copy.
- `deckUrl` is the return link from the audience page.
- `theme` maps the event palette to CSS variables.
- `difficulty.labels` must contain exactly five labels ordered from easiest to hardest.
- `question.maxPerDevice` accepts 1 to 100. The default is 20.
- `question.lenses` uses the four supported ids `clarify`, `chorus`, `bridge`, and `keeper`. Labels and descriptions are editable.
- `reactions` uses the four supported ids `applause`, `insight`, `resonate`, and `pause`. Emoji and labels are editable.
- `polls` accepts at most eight polls. Each poll needs a unique slug and two to six options.

## Wrangler variables

- `ROOM_ID` selects the room within an event configuration. Keep `default` for one deployment per event.
- `ALLOWED_ORIGINS` is a comma-separated exact allowlist for custom API clients. The embedded dashboard iframe does not need it.
- `ADMIN_TOKEN_SHA256` is generated by `npm run admin-token`. The plaintext token is stored only in `.live-deck-admin-token`.

## Admin operations

Export current state

```bash
curl -H "Authorization: Bearer $LIVE_DECK_ADMIN_TOKEN" https://SERVICE/api/admin/export
```

Reset current state

```bash
curl -X POST -H "Authorization: Bearer $LIVE_DECK_ADMIN_TOKEN" https://SERVICE/api/admin/reset
```

Resolve the exact service URL before running either command. Never print the token in logs or chat output.
